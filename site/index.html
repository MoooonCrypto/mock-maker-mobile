Features

スクリーンショットを、そのまま素材にしない。

MockMaker は、画面キャプチャをプレゼンや配信用の見せる画像に仕上げるためのツールです。 余計な設定より、すぐ書き出せることを優先しています。

テンプレート選択

シングル、ダブル、トップクロップ、スプリット、アイコン形式、フレームなしなどのレイアウトを用意しています。

背景と装飾

背景色、テキスト、スタンプ、メディアを組み合わせて、静止画だけで終わらないビジュアルを作れます。

そのまま保存

作成した画像は写真アプリや共有シートへそのまま書き出せます。作業は端末内完結です。

Details

アプリについて

MockMaker は日本語 UI を中心に設計された iOS アプリです。広告付きの基本利用に加えて、 買い切りの Pro で広告非表示とローカル保存の拡張機能を利用できます。

動作環境

  • iPhone 向け
  • iOS 15.1 以降
  • 画像選択と保存に写真ライブラリ権限を利用

データの扱い

  • モックアップ画像と編集内容は端末内で処理
  • アカウント登録は不要
  • 広告配信に Google AdMob を利用

購入オプション

  • 買い切り型の MockMaker Pro
  • 広告非表示
  • 作業中プロジェクトのローカル保存
