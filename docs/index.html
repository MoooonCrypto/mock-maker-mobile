MoooonCrypto（以下「開発者」）は、MockMaker（以下「本アプリ」）のご利用にあたり、 お客様のプライバシーを尊重し、個人情報の適切な保護に努めます。 本ポリシーは、本アプリが収集する情報とその取り扱いについて説明します。

1. 収集する情報

本アプリは以下の情報にアクセスします。

  • フォトライブラリ：モックアップの素材として画像を読み込む際、および作成したモックアップ画像を保存する際に使用します。画像データは端末内でのみ処理され、外部サーバーへ送信されることはありません。

本アプリはアカウント登録を必要とせず、氏名・メールアドレス・位置情報などの個人情報を収集しません。

2. 広告について（Google AdMob）

広告 SDK 使用

本アプリは、Google LLC が提供する広告サービス Google AdMob を使用しています。 AdMob は、広告のパーソナライズおよび効果測定のために、 広告識別子（IDFA / Advertising Identifier） を収集・使用することがあります。

収集されたデータは Google のプライバシーポリシーに従って処理されます。

  • Google プライバシーポリシー
  • AdMob のデータ収集について

iOS の設定アプリ（設定 → プライバシーとセキュリティ → トラッキング）から、 パーソナライズ広告のトラッキングを無効にすることができます。

3. データの保存・送信

本アプリで作成したモックアップ画像はお客様の端末内にのみ保存されます。 開発者のサーバーへのデータ送信は一切行いません。

4. 第三者サービス

本アプリが使用する第三者サービスは以下のとおりです。

  • Google AdMob（広告配信）

5. お子様のプライバシー

本アプリは13歳未満の方を対象としておらず、13歳未満の方から意図的に個人情報を収集することはありません。

6. プライバシーポリシーの変更

本ポリシーは必要に応じて更新されることがあります。 重要な変更がある場合は、本ページにて最終更新日を更新してお知らせします。 定期的にご確認いただくことをお勧めします。
